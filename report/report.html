九、踩坑记录

  1. pandas 3.0 兼容性：groupby.apply 返回值类型变化，导致 KeyError；改用显式循环。
  2. llama.cpp logprobs 字段：新版返回 top_logprobs 而非 probs，导致熵特征全为 0。
  3. 大模型 API 限流：qwen3.6-plus 硬限 1 req/s，2000+ 题跑 30 分钟。
  4. HF 镜像超时：base 模型加载联网检查，本地缓存后改离线模式解决。
  5. 多任务训练知识头崩盘：难度头梯度压制知识头，第 8 轮知识 F1 从 0.84 跌到 0.14；拆成两个独立模型后解决。
  6. Git 行尾符问题：PowerShell Set-Content 把 LF 改 CRLF，diff 虚报 3500 行改动；core.autocrlf true 解决。
  7. 难度 2 类样本不足：三模型都偏向判 0，最终 2 类占比仅 6.1%。
