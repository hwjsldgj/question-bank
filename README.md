# 自动出题与组卷工具（question-paper-generator）

面向教师与培训人员的桌面端自动出题与组卷工具：手工建库（选择题 + 解答题）、
AI API 自动标注难度（易/中/难）、按"评分决策 + 加权随机"选题
（近期重复抑制）、导出 TXT / PDF 试卷（卷末附答案页）。

- 需求文档：`.monkeycode/specs/question-paper-generator/requirements.md`
- 技术设计：`.monkeycode/specs/question-paper-generator/design.md`
- 架构说明：`docs/ARCHITECTURE.md`
- 依赖关系：`docs/DEPENDENCIES.md`
- 接口文档：`docs/INTERFACES.md`

## 功能特性

- 题库管理：单选 / 多选 / **填空** / 解答题的手工录入、批量粘贴、检索与质量标记；
  **科目为选择式录入**（列表在"设置 -> 科目管理"中维护，提供默认科目）
- 题库批量维护：多选批量删除（同时清理本地图片）、批量质量标记、
  批量重析难度（仅 AI 来源题目，人工难度不被覆盖）、题库概览统计
- 知识点自动补全：录入与检索的知识点输入框按已有知识点补全
- 界面可滚动：四个标签页均包在滚动容器中，窗口最大化或内容过高时上下滚动，不再错位
- 题目图片：可从本机导入题目图片，复制到数据库同级 `images/` 目录，
  库内只记录相对路径，列表显示图片有无，编辑时自动预览
- AI 辨识：一键识别科目 / 知识点 / 题型 / 难度 / 质量标记 / 答案 / 解析
  并回填表单，界面明确标注**结果仅供参考**，需人工复核后保存；
  可勾选"AI 不输出解析"要求 AI 只给答案
- AI 难度分析：OpenAI 兼容 API，失败自动降级为"待确认"；难度来源为人工时不被覆盖
- AI 提示词可改：辨识 / 难度分析 / AI 补题三个模板均可在"设置 -> AI 设置"中编辑并存本机
- 组卷引擎：单选 / 多选 / 填空 / 解答四类题型**各自独立启用**（单选与多选分开配置）；
  题库优先、AI 补题兜底
- 选题算法：难度匹配 / 知识点覆盖 / 使用频次 / 最近使用 / 人工质量
  五因子评分决策，再按评分加权随机抽样
- 近期重复抑制：使用记录 + 冷却窗口，最近用过的题目尽量少出现
- 历史与设置分开：历史页含组卷历史 / 导入历史（手工录入与批量导入）/ 编辑历史（修改与删除）；
  设置页含 AI 配置与提示词 / 评分与冷却 / 科目管理
- 保存前校验：题干与选项必须由出题者填写；其余信息（科目 / 知识点 / 答案 / 难度）
  不全时弹窗提供「AI 分析」选项补全，结果仅供参考
- 修改题目时可「取消编辑」退出编辑状态
- 试卷导出：TXT / PDF，按部分与题型分区、含小计与总分、卷末答案页

## 目录结构

```text
app/
├── domain/          领域层：实体、枚举、校验器（零外部依赖）
├── interfaces/      接口层：仓储 / 操作台账 / AI 客户端 / 导出器抽象（端口）
├── application/     应用服务层：题目服务与 AI 辨识、评分、抽样、组卷编排等用例
├── infrastructure/  基础设施层：SQLite 仓储、图片存储、AI 客户端、TXT/PDF 导出
├── presentation/    表现层：PySide6 主窗口与四个视图（题库 / 组卷 / 历史 / 设置）
├── config/          默认配置（评分权重 / 冷却窗口 / AI 参数 / 科目 / 提示词）
└── container.py     组合根：装配完整对象图
main.py              程序入口
docs/                架构 / 依赖 / 接口文档
tests/               冒烟测试（含表现层离屏测试）与专项用例
```

分层依赖方向与强制规则见 `docs/ARCHITECTURE.md`。

## 快速开始

```bash
# 安装依赖（含桌面 GUI、PDF 渲染、AI 访问与测试框架）
pip install -r requirements.txt

# 启动桌面应用
python main.py

# 运行测试
python -m pytest tests/ -v
```

首次启动自动在本地创建 `question_bank.db`（SQLite，需求 R18：数据仅存本机），
题目图片保存在同级的 `images/` 目录。
AI 功能需在"设置 -> AI 设置"页配置 API 地址、Key 与模型名称（并可修改提示词）；
未配置时题库管理、图片导入、检索与库内组卷仍可正常使用。
